# Horse Coat Color Simulator
Generate random horses and then cross them to see what kind of offspring they could have together.

## Future Plans
1. more and better art, like from a real artist and multiple options for different patterns like tobiano
2. more genes
3. complex gene interactions like leopard / appaloosa
4. ability to inspect genotype
5. ability to save horses to cross them later
6. more complex control of the rarity of genes
